# Library Management System

## Project Overview

An academic Database Management System (DBMS) project focused on designing and implementing a database for a Library Management System. The project covers the main stages of database development, including Entity-Relationship Diagram (ERD) design, relational schema development, and SQL implementation.

The system models key library operations, including book and category management, author and publisher information, member records, borrowing transactions, book copies, staff management, and fines.

## My Contribution

My primary responsibility was designing the Entity-Relationship Diagram (ERD), identifying the main entities and their attributes, and modeling the relationships and cardinalities between the components of the system.

## Project Scope

- **ERD Design:** Identifying entities, attributes, and relationships.
- **Relational Schema:** Translating the conceptual database design into a relational structure.
- **SQL Implementation:** Implementing the database using SQL.
